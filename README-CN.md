# ChronoPlanner

🇨🇳 中文 | [🇬🇧 English](./README.md)

> 一个基于生物节律为你安排每日计划的 Claude Skill。

ChronoPlanner 是一个 Claude Skill，基于**昼夜节律研究**、**注意力科学**和**多巴胺调控原理**生成科学的单日任务计划。它不是让你从上到下填满日历，而是把每项任务匹配到你的大脑在生理上最适合处理它的时间窗口。

中文版 Skill 文件：[SKILL-CN.md](./SKILL-CN.md)

---

## 有什么不同

大多数 AI 规划工具把一天的每个小时都当作相等的。ChronoPlanner 不这样做。

它根据你的实际起床时间动态计算个人精力窗口，然后相应地安排任务——皮质醇峰值时做深度专注，低谷期处理行政，睡前做复习。它还处理会让计划失效的实际摩擦：地点变化、通勤缓冲、固定锚点事件和疲劳预判。

**内置核心原则：**
- 皮质醇觉醒反应（CAR）与 BDNF 时机
- 注意力残留效应（任务切换后 23 分钟恢复期）
- 深度工作前的多巴胺降温
- 同类任务批量处理，减少上下文切换
- Eat the Frog — 最难的任务放在精力峰值
- 通勤时的主动+被动任务并行
- 疲劳预判 — 精力下降时安排行政，而非深度工作
- 延迟通勤调度 — 通勤 block 紧贴目标任务，不让你提前到达空等
- 自动推断午饭时间（如未填写）
- Google Calendar 同步 — 计划生成后可直接写入日历

## 适合谁

✅ 时间灵活的学生和知识工作者
✅ 同一天需要处理深度工作、行政和外出事项的人
✅ 有晨练习惯并想利用该窗口的人
✅ 尝试过时间块规划但觉得太死板的人

❌ 不适合完全固定朝九晚五、没有任何灵活空间的人
❌ 不是任务管理器——每次只规划单日，不处理长期项目

## 安装方式

### 方式 A — Claude.ai（网页 / 手机）

1. 进入 Claude.ai 的 **设置 → Skills**
2. 新建一个 Skill，将 `SKILL-CN.md` 的内容粘贴进去
3. 保存——当你说"帮我安排今天"时，ChronoPlanner 会自动触发

### 方式 B — Claude Code

```bash
mkdir -p ~/.claude/skills/chronoplanner
curl -o ~/.claude/skills/chronoplanner/SKILL.md \
  https://raw.githubusercontent.com/yitong0322/chronoplanner/main/SKILL-CN.md
```

### 方式 C — System Prompt（任何 Claude 界面或 API）

将 `SKILL-CN.md` 的全部内容复制，粘贴到你的 system prompt 字段。适用于 Claude API、Cursor 以及任何支持 system prompt 的工具。

## 工作流程

ChronoPlanner 用一条消息同时问完前三个核心问题，之后只针对缺失信息追问。如果你一开始就提供了所有信息，它会直接生成计划。

| 轮次 | 询问内容 | 时机 |
|------|---------|------|
| 1–3（合并） | 起床时间、计划范围、固定锚点事件 | 始终，合并为一条消息 |
| 4 | 今日任务清单 | 仅在未提供时询问 |
| 5 | 每项任务的时长、优先级、地点 | 仅针对缺失字段，逐任务询问 |
| 6 | 今日专注状态 + 期望结束时间 | 始终 |

所有轮次完成后，输出一段确认摘要，然后生成完整计划。

## 输出格式

```
[时间段] 🔵 任务名 (时长) — 一句话原因
[时间段] 😴 休息：推荐方式 (时长)
[时间段] 🍽️ 午饭（建议）— 可根据需要调整时间
[时间段] 🚌 通勤：家 → 咖啡馆 (20分钟) — 推荐：播客 / 有声书
[时间段] ⚪ 回邮件 (30分钟) — 能量低谷；仅处理行政
...
```

**图例**

| 图标 | 含义 |
|------|------|
| 🔵 | 深度专注任务 |
| 🟡 | 创意 / 协作 / 技能练习 |
| 🟢 | 复习巩固 |
| ⚪ | 行政 / 机械性任务 |
| 😴 | 休息（注明推荐方式）|
| 🍽️ | 午饭（固定或自动推断）|
| 🚌 | 通勤缓冲（紧贴目标任务前）|
| ☕ | 多巴胺降温 / 咖啡因摄入提示 |
| 🌙 | 放松 / 轻阅读 / 日记 |

只列出有内容的 block，空白时间段不解释。

**用户输入：**
> 7:00 起床，今天健身 45 分钟。任务：刷 LeetCode（60分钟，高优先级，家）、写读书笔记（60分钟，中，咖啡馆）、回邮件（30分钟，低，家）、Anki 复习（30分钟，中，家）、看技术视频（60分钟，低，家）。状态：一般。期望 21:00 前结束。

[08:15–09:00] 🔵 LeetCode (45分钟) — 皮质醇峰值；最难任务优先（Eat the Frog）
[09:00–09:10] 😴 休息：望向窗外 / 伸展 (10分钟)
[09:10–09:55] 🔵 LeetCode 续 (45分钟)
[09:55–10:05] 😴 休息：腹式呼吸 (10分钟)
[10:05–10:50] 🟡 写读书笔记 (45分钟) — 仍在黄金窗口；创意吸收类任务
[10:50–11:10] 🚌 通勤：家 → 咖啡馆 (20分钟) — 推荐：播客或语言听力

## Google Calendar + Apple Calendar 同步

计划生成后，ChronoPlanner 会询问是否添加到 Google Calendar。确认后，它会为计划中的每一个 block 单独创建日历事件——包括任务、休息、通勤和多巴胺降温期。

如果你的 iPhone 或 Mac 已连接 Google Calendar，Apple Calendar 会自动同步，无需额外操作。

## 自定义

这个 Skill 设计为可 fork 修改：

- **调整起床时间选项** — 编辑开场问题中的选项
- **添加晨间习惯类型** — 在核心科学原理的晨间习惯部分扩展
- **更换输出语言** — 默认跟随用户语言；也可在文件顶部指定固定语言
- **调整专注 block 时长** — 编辑注意力 Span 原理中的差/一般/好对照表

## 科学依据

ChronoPlanner 基于以下研究领域：

- **皮质醇觉醒反应（CAR）** — 醒后皮质醇激增，激活前额叶执行功能
- **BDNF 与运动** — 有氧运动提升脑源性神经营养因子，增强学习准备度
- **注意力残留效应** — Sophie Leroy 的研究：任务切换后约 23 分钟才能完全重新投入
- **多巴胺基线调控** — Anna Lembke 关于高刺激内容影响基线动机的研究
- **睡眠双过程模型** — 昼夜节律与睡眠压力的交互作用
- **间隔重复与记忆巩固** — 睡前复习对夜间记忆处理的影响
