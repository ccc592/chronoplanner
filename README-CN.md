# ChronoPlanner

🇨🇳 中文 | [🇬🇧 English](./README.md)

> 一个基于你的生物节律为你安排每日计划的 Claude Skill。

ChronoPlanner 是一个 Claude Skill，基于**昼夜节律研究**、**注意力科学**和**多巴胺调控原理**生成科学的单日和周计划。它把每项任务匹配到你的大脑在生理上最适合处理它的时间窗口——并随着使用不断学习你的习惯。

---

## 有什么不同

大多数 AI 规划工具把一天的每个小时都当作相等的。ChronoPlanner 不这样做。

它根据你的起床时间、chronotype 和睡眠质量动态计算个人精力窗口，然后相应安排任务。皮质醇峰值时做深度专注，低谷期处理行政，睡前做复习。它还处理会让计划失效的实际摩擦。

**核心功能：**
- **预扫描** — 在提任何问题之前，静默读取 Google Calendar、Tasks、Gmail、Notion、Todoist、Slack 和天气
- **Chronotype 感知** — 3 题 MEQ 问卷评估；夜猫子黄金窗口比早鸟晚 3–4 小时
- **睡眠校准 block** — 睡眠时长 × 主观感受 → 精准 block 长度（25 / 45 / 60–90 分钟）
- **多巴胺降温** — 深度工作前 60 分钟保护窗口
- **同类任务批量处理** — 通讯类集中在固定窗口；创意类连续不拆分
- **Eat the Frog** — 最难任务永远放在精力峰值
- **通勤感知** — 检测地点变化，🚌 通勤 block 紧贴目标任务前插入
- **任务依赖** — 任务 B 只在任务 A 完成后才安排
- **天气自适应休息** — 天气好才推荐户外休息
- **计划局部调整** — "我的会议推到 3 点了"只重排受影响的 block
- **月经周期感知** — 可选；按周期阶段调整 block 长度和休息频率
- **周计划模式** — 把任务分配到周一至周五，输出周视图摘要
- **端日复盘** — 说"今天结束了"触发；追踪完成率和计划质量
- **Pattern Learning** — 3 次以上数据后，对你经常低估的任务类型自动建议 buffer
- **习惯追踪** — 每日指标写入 Google Sheets；按需生成周报
- **Google Calendar / Notion / Obsidian 输出** — 计划生成后同步或导出

## 适合谁

✅ 时间灵活的学生和知识工作者
✅ 同一天需要处理深度工作、行政和外出事项的人
✅ 有晨练习惯并想利用该窗口的人
✅ 需要计划真正匹配自己生物节律的夜猫子
✅ 尝试过时间块规划但觉得太死板的人

❌ 不适合完全固定朝九晚五、没有任何灵活空间的人
❌ 不是长期项目管理工具——每次规划单日或单周

## 安装方式

### 方式 A — Claude.ai（网页 / 手机）

1. 进入 Claude.ai 的 **设置 → Skills**
2. 新建一个 Skill，将 `SKILL-CN.md` 的内容粘贴进去
3. 保存——当你说"帮我安排今天"时，ChronoPlanner 会自动触发

> **注意：** `references/` 文件夹包含 Claude 按需加载的支持文件，建议完整上传整个目录结构。

### 方式 B — Claude Code

```bash
git clone https://github.com/yitong0322/chronoplanner ~/.claude/skills/chronoplanner
```

### 方式 C — System Prompt（任何 Claude 界面或 API）

将 `SKILL-CN.md` 的全部内容粘贴到 system prompt 字段。适用于 Claude API、Cursor 以及任何支持 system prompt 的工具。

## 工作流程

### 第零步：预扫描（静默自动）

在提任何问题之前，ChronoPlanner 扫描已连接的工具并检查记忆：

| 来源 | 作用 |
|------|------|
| 🧠 记忆 | 加载已保存的 chronotype、起床时间、校准记录 |
| 📅 Google Calendar | 获取今日事件 → 自动锁定为锚点 |
| ✅ Google Tasks / Todoist / Linear / TickTick | 获取今日到期任务 |
| 📧 Gmail / Outlook | 扫描待办邮件（最多 5 条）|
| 📝 Notion | 展示标注今日/本周的页面 |
| 💬 Slack | 扫描 mentions/DM 中的行动项（最多 3 条）|
| 🌤️ 天气（网络搜索） | 获取实时天气 → 影响休息方式推荐 |

未连接的工具静默跳过。所有结果在提问前用一行摘要展示。

### 第一步：问卷

只询问预扫描未能回答的信息——开场问题合并为一条消息，逐任务单独询问缺失字段。

| 轮次 | 询问内容 | 时机 |
|------|---------|------|
| 1–3（合并） | 计划类型（日/周）、起床时间、固定锚点 | 始终；跳过预填内容 |
| 4 | 任务清单 | 仅在预扫描未找到时询问 |
| 5 | 时长、优先级、地点、依赖关系 | 仅针对缺失字段，逐任务询问 |
| 6 | 睡眠时长 + 感受、Chronotype（MEQ）、期望结束时间 | 始终 |

### 第二步：生成计划

确认摘要 → 完整注释时间表 → 询问是否同步到 Google Calendar、Notion 或 Obsidian。

### 第三步：端日复盘（可选）

任何时候说**"今天结束了"**触发 3 题复盘：
- 哪些任务完成 / 推迟 / 放弃？
- 计划质量评分（1–5）
- 精力是否符合预测？

结果自动进入 Pattern Learning 和习惯追踪。

## 科学依据

- **皮质醇觉醒反应（CAR）** — 醒后皮质醇激增，激活前额叶执行功能
- **BDNF 与运动** — 有氧运动提升脑源性神经营养因子，持续 2–4 小时
- **注意力残留效应**（Sophie Leroy，2009）— 任务切换后约 23 分钟才能完全重新投入
- **多巴胺基线调控**（Anna Lembke）— 高刺激内容拉高基线，造成对专注任务的结构性抵触
- **睡眠双过程模型** — 昼夜节律与睡眠压力的交互作用
- **间隔重复与记忆巩固** — 睡前复习最大化隔夜记忆留存
